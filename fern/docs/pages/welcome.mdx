## Get started

aVenture covers private companies, their founders, investors, funding rounds,
and news. Every way in needs an aVenture account; free and paid plans both work.
[Create an account](https://aventure.vc/sign-up), then pick where you work:

| Where you work | Use | Setup |
|---|---|---|
| Claude, ChatGPT, or another desktop, web, or cloud AI app | [MCP server](/mcp) | Add a connector; nothing to install |
| A terminal, shell scripts, or a coding agent with a shell | [CLI](/cli) | One `npm install` |
| [Researchly](https://researchly.chat) | Built in | Open [Profile, then MCP servers](https://researchly.chat/profile/mcp-servers) and choose **Connect aVenture** |
| Your own code | [API](/quickstart) | An API key |

The MCP and CLI quickstarts each start with a prompt you can paste into your AI
app to set everything up for you.

counts, and the [pricing page](https://aventure.vc/pricing) lists current plans.

## Working in TypeScript

Request and response types are published as [`@aventurevc/api-schemas`](https://www.npmjs.com/package/@aventurevc/api-schemas)
on npm. The package contains Zod schemas and TypeScript types only, so use
`fetch` or any HTTP library to send requests.

```bash
npm install @aventurevc/api-schemas
```
