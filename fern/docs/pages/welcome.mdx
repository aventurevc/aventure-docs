## Get started

aVenture data covers private companies, their founders, investors, funding
rounds, and news. The API, CLI, and MCP server all require an aVenture account,
and free and paid plans both work. [Create an account](https://aventure.vc/sign-up),
then pick the tool you want to work in. Each quickstart ends with a real answer.

Profile views, searches, and web searches draw on your plan's monthly
allowances. [Plans and usage](/authentication#plans-and-usage) explains what
counts, and the [pricing page](https://aventure.vc/pricing) lists current plans.

<Tabs>
<Tab title="API">

```bash
curl -H "Authorization: Bearer $AUTH_TOKEN" \
  "https://api.aventure.vc/v1/entities/lookup-exact?urlDomain=stripe.com"
```

</Tab>
<Tab title="CLI">

```bash
npm install --global @aventurevc/aventure-cli
aventure auth login
aventure lookup Stripe
```

</Tab>
<Tab title="MCP">

Add `https://mcp.aventure.vc/mcp` to your client with OAuth client ID
`KL7mINzGk0le0QiD`, sign in, and ask a question such as "Who founded Ramp and
how much has it raised?" The [MCP quickstart](/mcp) has the setup for each
client.

</Tab>
</Tabs>

<Note>
The CLI and the self-hosted MCP server require Node.js 24.18 or later in the 24.x series.
</Note>

## Working in TypeScript

Request and response types are published as [`@aventurevc/api-schemas`](https://www.npmjs.com/package/@aventurevc/api-schemas)
on npm. The package contains Zod schemas and TypeScript types only, so use
`fetch` or any HTTP library to send requests.

```bash
npm install @aventurevc/api-schemas
```
