## Get started

aVenture data covers private companies, their investors, funding rounds,
people, and news. Pick the tool you want to work in. Public API and CLI reads
work without an account, and MCP requires sign-in. Each quickstart ends with a
working query.

Calls made with your credential draw on your plan's monthly allowances.
[Plans and usage](/authentication#plans-and-usage) explains what counts and
where to check your usage, and the [pricing page](https://aventure.vc/pricing)
lists current plans.

<CardGroup cols={3}>
  <Card title="API quickstart" icon="duotone plug" href="/quickstart">
    Send plain HTTPS requests with `curl`. No account is required to start.
  </Card>

  <Card title="CLI quickstart" icon="duotone terminal" href="/cli">
    Query from your terminal, sign in through your browser, and script against stable output and exit codes.
  </Card>

  <Card title="MCP quickstart" icon="duotone robot" href="/mcp">
    Give an AI client the data as tools. The hosted server needs no install.
  </Card>
</CardGroup>

<Tabs>
<Tab title="API">

```bash
curl "https://api.aventure.vc/v1/entities/summary?typeRecord=Company&size=5"
```

</Tab>
<Tab title="CLI">

```bash
npm install --global @aventurevc/aventure-cli --@aventurevc:registry=https://registry.npmjs.org/
aventure entities summary list --type-record Company --size 3
```

</Tab>
<Tab title="MCP">

The [MCP quickstart](/mcp) configures the hosted server, signs you in, and ends
with a first company research question. It lists the client ID and callback
settings that Claude Code requires, plus self-hosting instructions.

</Tab>
</Tabs>

<Note>
The CLI and the self-hosted MCP server require Node.js 24.18 or later in the 24.x series.
</Note>

## Working in TypeScript

Request and response types are published as [`@aventurevc/api-schemas`](https://www.npmjs.com/package/@aventurevc/api-schemas)
on npm. The package contains Zod schemas and TypeScript types only, so use
`fetch` or any HTTP library to send requests.

```bash
npm install @aventurevc/api-schemas --@aventurevc:registry=https://registry.npmjs.org/
```
