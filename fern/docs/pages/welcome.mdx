The aVenture API serves structured venture data over HTTP at `https://api.aventure.vc`.
Every response is JSON, every list is paginated, and every endpoint is documented
in the [API reference](/api-reference).

## What you can query

<CardGroup cols={3}>

## Get started

<Steps>
<Step title="Get a credential">

The API accepts three credential types, and which one you hold decides what you
can do. Read [Authentication](/authentication) to pick the right one.

</Step>
<Step title="Make a request">

Every call is a plain HTTPS request — no SDK required:

```bash
curl -H "X-Client-Secret: $AVENTURE_CLIENT_SECRET" \
  "https://api.aventure.vc/v1/entities?size=5"
```

The [quickstart](/quickstart) walks through the first few calls in full.

</Step>
<Step title="Narrow the results">

`GET /v1/entities` alone accepts more than sixty filters. [Pagination and
filtering](/pagination-and-filtering) covers how to combine them and page through
the results.

</Step>
</Steps>

## Working in TypeScript

Request and response types are published as [`@aventurevc/api-schemas`](https://www.npmjs.com/package/@aventurevc/api-schemas)
on npm. It is a schema package, not a client — bring your own HTTP layer.

```bash
npm install @aventurevc/api-schemas
```
