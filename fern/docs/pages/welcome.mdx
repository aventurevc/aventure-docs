## Get started

Pick the surface you want to work in. API and CLI public reads work before
sign-in; MCP requires an authenticated connection. Each quickstart ends with
a working query. [Authentication](/authentication) explains which operations
need sign-in or a subscription.

<CardGroup cols={3}>
  <Card title="API quickstart" icon="duotone plug" href="/quickstart">
    Plain HTTPS requests. Start anonymously with `curl`, no signup required.
  </Card>

  <Card title="CLI quickstart" icon="duotone terminal" href="/cli">
    Query from your terminal. Sign in through your browser; scriptable output and exit codes.
  </Card>

  <Card title="MCP quickstart" icon="duotone robot" href="/mcp">
    Give an AI client the data as tools. The hosted server needs no install.
  </Card>
</CardGroup>

<Tabs>
<Tab title="API">

```bash
curl "https://api.aventure.vc/v1/entities?size=5"
```

</Tab>
<Tab title="CLI">

```bash
npm install --global @aventurevc/aventure-cli --@aventurevc:registry=https://registry.npmjs.org/
aventure entities list --size 3
```

</Tab>
<Tab title="MCP">

Follow the [MCP quickstart](/mcp) to configure the hosted server, complete
sign-in, and ask your first company research question. It includes the client
ID and callback settings required by Claude Code, plus self-hosting instructions.

</Tab>
</Tabs>

<Note>
Both packages require Node.js 24.18 or later in the 24.x series.
</Note>

## Working in TypeScript

Request and response types are published as [`@aventurevc/api-schemas`](https://www.npmjs.com/package/@aventurevc/api-schemas)
on npm. It ships schemas and types only — bring your own HTTP layer.

```bash
npm install @aventurevc/api-schemas --@aventurevc:registry=https://registry.npmjs.org/
```
