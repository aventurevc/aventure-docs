## Get started

Pick the surface you want to work in. All three read the same data and accept
the same credentials, and each quickstart ends with a working query.

<CardGroup cols={3}>
  <Card title="API quickstart" icon="duotone plug" href="/quickstart">
    Plain HTTPS requests. Start anonymously with `curl`, no signup required.
  </Card>

  <Card title="CLI quickstart" icon="duotone terminal" href="/cli">
    Query from your terminal. Sign in through your browser; scriptable output and exit codes.
  </Card>

  <Card title="MCP quickstart" icon="duotone robot" href="/mcp">
    Give an AI client the data as tools. The hosted server needs no install.
  </Card>
</CardGroup>

<Tabs>
<Tab title="API">

```bash
curl "https://api.aventure.vc/v1/entities?size=5"
```

</Tab>
<Tab title="CLI">

```bash
npm install --global @aventurevc/aventure-cli --registry=https://registry.npmjs.org/
aventure entities list --size 3
```

</Tab>
<Tab title="MCP">

Point an OAuth-capable client at `https://mcp.aventure.vc/mcp` with the public
client ID `KL7mINzGk0le0QiD`, or self-host:

```bash
npm install --global @aventurevc/mcp-server --registry=https://registry.npmjs.org/
aventure-mcp-server
```

</Tab>
</Tabs>

<Note>
Both packages require Node.js 24.18 or later in the 24.x series.
</Note>

## Your first request

<Steps>
<Step title="Read something without signing in">

`GET /v1/entities` and the other public listings answer with no credential at
all, so you can see the data shape before you commit to anything:

```bash
curl "https://api.aventure.vc/v1/entities?size=5"
```

</Step>
<Step title="Get a credential">

Create a personal API key under **Settings → API keys** at
[aventure.vc](https://aventure.vc). [Authentication](/authentication) explains
the three credential types and which operations accept each one.

</Step>
<Step title="Narrow the results">

`GET /v1/entities` alone accepts more than sixty filters. [Pagination and
filtering](/pagination-and-filtering) covers how to combine them and page through
the results.

</Step>
</Steps>

## Working in TypeScript

Request and response types are published as [`@aventurevc/api-schemas`](https://www.npmjs.com/package/@aventurevc/api-schemas)
on npm. It ships schemas and types only — bring your own HTTP layer.

```bash
npm install @aventurevc/api-schemas
```
