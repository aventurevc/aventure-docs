Go from an API key to real answers: a company by website, by name, or by
description, then a person, then funding rounds.

## 1. Create an API Key

The API requires an aVenture account. Free and paid plans both work.

1. [Create an account](https://aventure.vc/sign-up), or sign in.
2. Open [API Keys settings](https://aventure.vc/settings/api-keys) and choose
   **Add new key**.
3. Load the key from your secret manager into `AUTH_TOKEN`, so it never lands
   in your shell history.

Every request sends the key as a bearer token:

```bash
curl -H "Authorization: Bearer $AUTH_TOKEN" \
  "https://api.aventure.vc/v1/auth/me/permissions"
```

## 2. Find a Company by Its Website

```bash
curl -H "Authorization: Bearer $AUTH_TOKEN" \
  "https://api.aventure.vc/v1/entities/lookup-exact?urlDomain=stripe.com"
```

The response is the full company profile: identity in `core`, including the
`core.id` that other requests take, plus research, funding, people, and news.

## 3. Find a Company by Name

Steps 3 to 5 need a paid plan (AI Plus or AI Pro); on the free plan they answer
`402` with `code` `subscription_required`. Step 2's website lookup and step 6 work
on every plan.

`POST /v1/lookup` decides which company or person a name refers to. Add a
website, a location, or a few words of context to tell namesakes apart:

```bash
curl -X POST \
  -H "Authorization: Bearer $AUTH_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "Mercury", "context": "banking for startups"}' \
  "https://api.aventure.vc/v1/lookup"
```

The answer says whether the name matched a record and, when it did, returns the
record's `id` and `slug`. [Identify a company or person](/lookup) explains each
answer.

## 4. Find Companies by Describing Them

When you don't know the name, describe what you're looking for.
`POST /v1/search` searches companies, people, and news together:

```bash
curl -X POST \
  -H "Authorization: Bearer $AUTH_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "seed-stage climate software companies in Austin"}' \
  "https://api.aventure.vc/v1/search?size=10"
```

## 5. Find a Person

By name, with context:

```bash
curl -X POST \
  -H "Authorization: Bearer $AUTH_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "Patrick Collison", "context": "Stripe co-founder"}' \
  "https://api.aventure.vc/v1/people/lookup"
```

By LinkedIn profile, pass the profile in `url` instead:
`{"name": "Patrick Collison", "url": ["https://www.linkedin.com/in/patrickcollison"]}`.
To find people by description, use the same `POST /v1/search` as step 4, such as
`{"query": "fintech founders who previously worked at PayPal"}`.

## 6. Read a Company's Funding Rounds

Set `ENTITY_ID` to `core.id` from step 2 and list its rounds:

```bash
ENTITY_ID=<core.id from step 2>
curl -H "Authorization: Bearer $AUTH_TOKEN" \
  "https://api.aventure.vc/v1/entities/$ENTITY_ID/fundraise-rounds?size=5"
```

## Plans and Usage

Calls draw on your plan's monthly allowances. When one runs out, the API answers
`429` with `code` `billing_allowance_exhausted`.
[Plans and usage](/plans-and-usage) explains what counts and how to upgrade.
