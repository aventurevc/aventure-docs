Connect ChatGPT, Claude, Gemini, or any MCP client to aVenture's hosted
server, then ask in plain English. You need an
[aVenture account](https://aventure.vc/sign-up); free and paid plans both work.
Working in a terminal or a coding agent with a shell? Use the [CLI](/cli). In
[Researchly](https://researchly.chat), aVenture is built in: open
[Profile, then MCP servers](https://researchly.chat/profile/mcp-servers) and
choose **Connect aVenture**.

## Choose Your AI App

Use the hosted URL `https://mcp.aventure.vc/mcp` with **Streamable HTTP** and
**OAuth**. aVenture already supports OAuth discovery through Clerk. Let your
client discover and register its OAuth client automatically (DCR). Leave
manually entered client credentials empty for this flow.
Sign in to your aVenture account and approve the access requested.

Adding a connector and authorizing it are separate steps. A setup prompt can
perform the steps its app exposes; account consent still happens in the sign-in
screen. The prompts below also verify the connection with a real company read.

A full-profile lookup can return a compact response. Check `truncated` and
`omitted` before calling its embedded funding, people, or news complete. To
recover a section, read its paginated sub-resource using the returned record
id; repeating the same profile lookup does not recover the omitted rows.

<Tab title="ChatGPT">

1. Open [ChatGPT Plugins](https://chatgpt.com/plugins) **on the web**.
2. Select **+**, then **Add custom MCP server**.
3. Name it **aVenture** and enter `https://mcp.aventure.vc/mcp`.
4. Choose **OAuth** and **automatic client registration (DCR)**. Leave the

5. Review the access notice and select **Create as a plugin**.
6. Install the resulting plugin, then complete aVenture's sign-in when prompted.

Creation alone does not install the plugin in a conversation. Custom MCP setup
uses ChatGPT's web interface; check the installed plugin's availability in your
mobile app before using it there.

aVenture account is connected. Use aventure_help with resolve:true to find the exact

returned data, link its aVenture profile if returned, and state any missing

<Tab title="Gemini CLI">

Add the remote HTTP server at user scope:

```bash
gemini mcp add --scope user --transport http aventure https://mcp.aventure.vc/mcp
```

Open Gemini CLI, run `/mcp auth aventure`, and complete browser authorization.
Use `/mcp list` to confirm the connection. OAuth requires a browser and a
reachable loopback callback on the same machine; a headless remote session
needs its own compatible authentication route.

Gemini CLI's default OAuth callback path is `/oauth/callback`. Use discovery
and automatic registration. The fallback OAuth client below registers the
different path `/callback`; it is not a universal Gemini CLI fallback.

<Accordion title="Fallback for Clients That Need a Fixed OAuth Client">

Use aVenture's existing public client only when automatic OAuth client
registration is unavailable:

| Setting | Value |
|---------|-------|
| Server URL | `https://mcp.aventure.vc/mcp` |
| Transport | Streamable HTTP |
| OAuth client ID | `KL7mINzGk0le0QiD` |
| OAuth client secret | Leave empty |

The fixed client has these registered redirect URIs:

- `http://127.0.0.1/callback`
- `http://localhost/callback`
- `https://chatgpt.com/connector_platform_oauth_redirect`
- `https://claude.ai/api/mcp/auth_callback`

A loopback redirect may use any available port while keeping its `/callback`
path. These restrictions belong to the fixed client, not all discovered or
automatically registered clients. A client with a different callback needs a
compatible registration; [contact support](/support) if its automatic
registration fails.

For a Claude Code version that needs the fixed client:

```bash
claude mcp add --scope user --transport http \
  --client-id KL7mINzGk0le0QiD --callback-port 6276 \
  aventure https://mcp.aventure.vc/mcp
```

Then sign in through `/mcp`.

</Accordion>

## Troubleshooting

| What you see | Fix |
|---|---|
| Connected app exists but tools are unavailable | Install/enable it in the current conversation and verify with `aventure_status` |
| OAuth client registration fails | Check the client's discovery/registration choice; use the fixed client only for its supported redirect URIs |
| Redirect URI mismatch | Check the actual callback against the OAuth client used; a different callback path needs a compatible registration |
| Sign-in succeeds but connector remains disconnected | Check whether token exchange and tools discovery finished; provide the exact client error to [support](/support) |
| `401` on a previously working connection | Reconnect in your client's account settings; in Claude Code, use `/mcp` and sign in again |
| `402` with `subscription_required` | On the free plan, read by website or [upgrade](/plans-and-usage) |
| `429` with `billing_allowance_exhausted` | [Upgrade](/plans-and-usage) or wait for the allowance reset |

`aventure_status` verifies the live connection and shows the signed-in account.
Use a website such as `https://stripe.com` for the first read so the check works
on free as well as paid plans.

## Ask Your First Question

Once connected, ask things like:

- "Look up Stripe on aVenture and summarize its funding history."
- "Which company owns ramp.com, and who founded it?"
- "Find seed-stage climate software companies in Austin."
- "Who is Patrick Collison, and which companies is he connected to?"
- "Find fintech founders who previously worked at PayPal."

<Note>
Finding a company or person by name or description needs a paid plan (AI Plus
or AI Pro). On the free plan, ask by website: "Read aVenture's profile for
ramp.com."
</Note>

The assistant picks the tools itself:

| Tool | What it does |
|------|--------------|
| `aventure_lookup` | Finds a company or person by name, website, or LinkedIn URL |
| `aventure_search` | Finds companies, people, and news from a description |
| `aventure_read` | Reads a full profile and its funding rounds, people, and news |
| `aventure_help` | Finds the right operation for a task |
| `aventure_status` | Confirms the connection and your sign-in |

Calls draw on your plan's monthly allowances. When one runs out, the answer
names the limit and how to upgrade; you can also ask the assistant to list plans
or upgrade you. [Plans and usage](/plans-and-usage) has the details. To call the
tools from your own code or prompts, read
[Call MCP tools directly](/mcp-tools).

<Accordion title="Run the Server Yourself (Rarely Needed)">

Run the server yourself only when your client can't
complete an OAuth sign-in, or when you need it inside your own network. It
requires Node.js 24.18.0 or later.

```bash
npm install --global @aventurevc/mcp-server
aventure-mcp-server
```

It listens at `http://localhost:3333/mcp`. Leave it running while your client is
connected, and send an [API key](/authentication#create-an-api-key) as a bearer
token on every request:

```json
{
  "mcpServers": {
    "aventure": {
      "type": "http",
      "url": "http://localhost:3333/mcp",
      "headers": {
        "Authorization": "Bearer <your-api-key>"
      }
    }
  }
}
```

Supply the key through your client's secret storage. Never paste it into a file
you commit. `AVENTURE_MCP_PORT` and `AVENTURE_MCP_PATH` change the port and
route; update the client URL to match. The server speaks Streamable HTTP, so
configure a URL, not a command.

</Accordion>
