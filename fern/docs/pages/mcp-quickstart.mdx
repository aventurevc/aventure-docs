Connect ChatGPT, Claude, Grok, Gemini, Perplexity, Cursor, or any MCP client to aVenture's
hosted server, then ask about private companies, their people, funding rounds,
investors, and news. You need an
[aVenture account](https://aventure.vc/sign-up); the free plan works. For a
terminal or a coding agent with a shell, use the [CLI](/cli). In
[Researchly](https://researchly.chat), aVenture is built in: open
[Profile, then MCP servers](https://researchly.chat/profile/mcp-servers) and
choose **Connect aVenture**.

## Choose Your AI App

Every app connects to the same hosted server:

| Setting | Value |
|---------|-------|
| Server URL | `https://mcp.aventure.vc/mcp` |
| Transport | Streamable HTTP |
| Authentication | OAuth sign-in in your browser |

When the app opens aVenture's sign-in page, sign in to your aVenture account and
approve the access it asks for. Most tabs end with a one-shot prompt to paste
into that app; it finishes setup and runs a first lookup.

<Tabs>
<Tab title="ChatGPT">

1. Open [ChatGPT Plugins](https://chatgpt.com/plugins) **on the web**.
2. Select **+**, then **Add custom MCP server**.

5. Review the access notice and select **Create as a plugin**.

Creation alone does not install the plugin in a conversation. Custom MCP setup
uses ChatGPT's web interface; check the installed plugin's availability in your

## Troubleshooting

| What you see | Fix |
|---|---|
| Connected app exists but tools are unavailable | Install/enable it in the current conversation, then ask it to look up `https://stripe.com` on aVenture |
| Sign-in succeeds but connector remains disconnected | Check whether token exchange and tools discovery finished; provide the exact client error to [support](/support) |
| `401` on a previously working connection | Reconnect in your client's account settings; in Claude Code, use `/mcp` and sign in again |
| `402` with `subscription_required` | On the free plan, read by website or [upgrade](/plans-and-usage) |
| `429` with `billing_allowance_exhausted` | [Upgrade](/plans-and-usage) or wait for the allowance reset |

A lookup by website such as `https://stripe.com` verifies the live connection
and works on free as well as paid plans. To see which account and plan the
connection uses, ask the assistant to read your aVenture subscription
(`aventure_read` with operation `getBillingSubscription`).

## Ask Your First Question

Once connected, ask things like:

- "Look up Stripe on aVenture and summarize its funding history."
- "Which company owns ramp.com, and who founded it?"
- "Find seed-stage climate software companies in Austin."
- "Who is Patrick Collison, and which companies is he connected to?"
- "Find fintech founders who previously worked at PayPal."

<Note>
The free plan finds 20 companies or people by name a day and includes a daily
allowance of plain-English company and people searches, such as "Who founded
Ramp?" Link search, page reads, and research runs need a paid plan
([AI Plus or AI Pro](https://aventure.vc/pricing)). Past a daily allowance, ask
by website:
"Read aVenture's profile for ramp.com."
</Note>

The assistant picks the tools itself:

| Tool | What it does |
|------|--------------|
| `aventure_lookup` | Identifies a company or person by name, website, or LinkedIn URL |
| `aventure_search` | Runs the search operation that `aventure_help` names; pass the search text in its `query` or `body` |
| `aventure_read` | Reads a profile and its funding rounds, people, and news |
| `aventure_help` | Finds the operation for a task described in plain English |
| `aventure_job` | Queues research on a company or person, or a bulk lookup job |

No tool edits or deletes aVenture records on your behalf.

A long profile can come back shortened. When a result reports `truncated` or
`omitted`, ask for the missing funding rounds, people, or news by name; the
assistant reads them page by page.

Calls draw on your plan's monthly allowances. When one runs out, the answer
names the limit and how to upgrade; the assistant can list plans, and
[Plans and usage](/plans-and-usage) shows where to upgrade. To call the
tools from your own code or prompts, read
[Call MCP tools directly](/mcp-tools).

<Accordion title="Run the Server Yourself (Rarely Needed)">

Run the server yourself when you need it inside your own network. It requires
Node.js 24.18.0 or later.

```bash
npm install --global @aventurevc/mcp-server
aventure-mcp-server
```

It listens at `http://localhost:3333/mcp`. Leave it running while your client is
connected, and send an [API key](/authentication#create-an-api-key) as a bearer
token on every request:

```json
{
  "mcpServers": {
    "aventure": {
      "type": "http",
      "url": "http://localhost:3333/mcp",
      "headers": {
        "Authorization": "Bearer <your-api-key>"
      }
    }
  }
}
```

Supply the key through your client's secret storage. Never paste it into a file
you commit. `AVENTURE_MCP_PORT` and `AVENTURE_MCP_PATH` change the port and
route; update the client URL to match. The server speaks Streamable HTTP, so
configure a URL, not a command.

</Accordion>
