## Another MCP Client

Add a remote server named **aVenture**:

```text title="MCP server URL" wordWrap
https://mcp.aventure.vc/mcp
```

- **Transport:** Streamable HTTP
- **Authentication:** OAuth (sign in to aVenture in your browser)

If asked how to register the OAuth client, choose automatic registration. You do not need a client secret for browser sign-in.

## Troubleshooting

- **Your answer comes from the web.** Enable or select aVenture in this chat and allow the tool to run.
- **The connector only answers questions about these docs.** A URL ending in `/_mcp/server` searches documentation, not company data. Use the server URL above.
- **The URL shows `405` in your browser.** Paste it into the connector settings. It is not a web page.
- **Sign-in finished, but the app still shows aVenture as disconnected.** Return to the connector settings and select **Connect** or **Authenticate**. If it still fails, tell [support](/support) the app name, failed step, and exact error. Leave out tokens, keys, and sign-in links.
- **A connection that worked before now returns `401`.** Sign in again from the connector settings. In Claude Code, open `/mcp`.
- **A tool returns `402` (`subscription_required`).** The app reached aVenture. Try the lookup above or check [which plan includes the feature](/plans-and-usage).
- **A tool returns `429`.** Check what limit you reached and when to retry in [Plans and usage](/plans-and-usage#when-you-reach-a-limit).

## Run the Server Yourself

If you need the server inside your own network, use Node.js 24.22.1 or a newer 24.x release:

```bash
npm install --global @aventurevc/mcp-server
aventure-mcp-server
```

Leave it running and set `http://localhost:3333/mcp` as the URL in your MCP client. Use Streamable HTTP and send an [aVenture API key](/authentication#create-an-api-key) as the bearer token:

```json
{
  "mcpServers": {
    "aventure": {
      "type": "http",
      "url": "http://localhost:3333/mcp",
      "headers": { "Authorization": "Bearer <your-api-key>" }
    }
  }
}
```

Keep the key in secret storage, not version control. If you change `AVENTURE_MCP_PORT` or `AVENTURE_MCP_PATH`, update the URL in your client. The package is on [npm](https://www.npmjs.com/package/@aventurevc/mcp-server) and its source is on [GitHub](https://github.com/aventurevc/aventure-mcp).
