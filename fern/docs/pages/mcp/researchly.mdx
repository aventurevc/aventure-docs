## Connect aVenture in Researchly

aVenture is built into Researchly, so you don't need to enter a server URL. Open [Profile → MCP servers](https://researchly.chat/profile/mcp-servers), choose **Connect aVenture**, and sign in with your aVenture account. A [free aVenture account](https://aventure.vc/sign-up) works without an API key.
