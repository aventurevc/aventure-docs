Endpoints are grouped by what they operate on: entities, people, news,
fundraising, media, search, and classifications. Every endpoint except the plan
list and the status check requires an aVenture account; [create one](https://aventure.vc/sign-up) and send an API key
or OAuth access token as described in [Authentication](/authentication).

## Before You Start

- **[Authentication](/authentication)** covers API keys and sign-in. Many
  `POST` endpoints are reads that carry a JSON query.
- **[Plans and usage](/plans-and-usage)** covers allowances and upgrades.
- **[Pagination and filtering](/pagination-and-filtering)** covers the
  parameters for list endpoints.
- **[Errors](/errors)** covers error bodies and usage limits.

## Types for TypeScript

Request and response types are published as
[`@aventurevc/api-schemas`](https://www.npmjs.com/package/@aventurevc/api-schemas).
It contains Zod schemas and types, so use `fetch` or any HTTP library to send
requests.

```bash
npm install @aventurevc/api-schemas
```
