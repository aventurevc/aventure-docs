## Contact us

Use the [contact form](https://aventure.vc/forms/contact) to reach the aVenture
team about API access, credentials, or anything not covered here.

## Report a problem with the API

Send the endpoint and method, timestamp, and any `traceId` from the
[problem detail](/errors) through the contact form. For CLI or MCP problems,
include the package version, failed command or tool name, and error status.
Remove credentials, personal identifiers, and private response data before
sharing a transcript; send account-specific diagnostics privately.

## Report a problem with these docs

Open an issue on [aventurevc/aventure-docs](https://github.com/aventurevc/aventure-docs/issues).
The **Edit this page** link opens the Fern editor. Include the page URL and
a minimal example in a public issue; keep account details and session logs
in the private support conversation.
