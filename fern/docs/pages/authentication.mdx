The public API contract defines two access modes:

- An operation with no `security` declaration in the [API reference](/api-reference)
  is anonymous. `GET /v1/entities` and `GET /v1/entities/lookup` are examples.
- An operation that declares bearer authentication accepts a personal API key or
  OAuth access token in the `Authorization` header.

HTTP method alone does not determine access: a `POST` can be a read that carries
a JSON query. Use each operation's security and response declarations.

## Get a personal credential

Public users can create their own personal API key. Sign in at
[aventure.vc](https://aventure.vc), choose your account menu → **Manage account**,
open **API keys**, and choose
**Add new key**. Store the key in your secret manager and inject it as
`AUTH_TOKEN` at runtime. Never commit or print the key itself.

The CLI signs you in for you. `aventure auth login` runs the OAuth device
authorization grant — it prints a one-time code and a URL, and works over SSH
and in containers as well as on a laptop. `aventure auth login --key` creates
and stores a personal API key through the same browser approval instead. In a
non-interactive environment, supply an existing key through `AUTH_TOKEN`. The
[CLI quickstart](/cli) walks through both, and the [MCP quickstart](/mcp)
covers OAuth and personal-key clients.

## Connect an MCP client with OAuth

The [MCP quickstart](/mcp#connect-to-the-hosted-server) owns the hosted URL,
public client ID, callback configuration, and first connection check. MCP
requires authentication even for tools that call anonymous API operations.

## Verify personal API access

Send your personal key or OAuth access token as a bearer token:

```bash
curl -H "Authorization: Bearer $AUTH_TOKEN" \
  "https://api.aventure.vc/v1/auth/me/permissions"
```

This confirms that the API recognizes the bearer token and returns its resolved
permissions.

## Subscription-gated operations

Some operations need a subscription in addition to a bearer token. The public
reference declares `402` for natural-language search, link search, and
enrichment requests. It means the account needs an active or trialing
subscription tier that includes the feature. Use
[Settings → Subscription](https://aventure.vc/settings/subscription) to inspect
the account's plan; [Errors](/errors) explains the response body.

Filtered public lists and lookups remain available without a subscription.

## Keeping credentials safe

Credentials are bearer-equivalent: anyone holding the string has the
access it grants. Keep them server-side, load them from your secret manager at
runtime, and never ship one in browser code or commit one to a repository.

## When authentication fails

A missing, malformed, or unrecognized bearer token returns `401`. A recognized
token that is not permitted on an endpoint returns `403`. Both arrive in the
standard [problem detail](/errors) body, whose `detail` field names the specific
reason.
