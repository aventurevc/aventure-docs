## The aVenture API is publicly documented

The aVenture API surface is now published as an OpenAPI specification and
rendered as a browsable reference. It covers entity, person, news, fundraising,
media, search, and classification endpoints under `https://api.aventure.vc/v1`.

Request and response types ship separately as
[`@aventurevc/api-schemas`](https://www.npmjs.com/package/@aventurevc/api-schemas)
on npm — schemas and TypeScript types, no generated client.
